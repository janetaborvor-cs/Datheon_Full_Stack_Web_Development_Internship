# TaskFlow — Productivity Task Manager

TaskFlow is a responsive productivity web application built for the Datheon Full Stack Web Development Internship Task 2. It helps users organize daily activities, manage deadlines, and track their progress through a clean, Cotton Candy-inspired interface.

## Features

- **Create tasks:** Add tasks with titles, descriptions, categories, and due dates.
- **Read tasks:** View and organize your task list.
- **Update tasks:** Edit existing task details.
- **Delete tasks:** Remove tasks you no longer need.
- **Task completion:** Mark tasks as completed or active.
- **Categories:** Organize tasks into Work, Personal, Study, and Other.
- **Filtering:** Filter tasks by All, Active, or Completed status.
- **Search and sorting:** Find tasks and organize them using the available controls.
- **Local storage:** Save tasks in your browser so they remain after refreshing the page.
- **Responsive design:** Use the application on desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Browser localStorage API

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Start creating and managing tasks.

No backend server or database is required.

## Data Storage

TaskFlow uses the browser's localStorage API to persist task data on the same browser and device. Clearing browser site data may remove saved tasks.
