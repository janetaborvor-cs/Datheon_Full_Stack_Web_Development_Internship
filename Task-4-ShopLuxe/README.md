# ShopLuxe — E-Commerce Storefront

ShopLuxe is a modern, responsive e-commerce storefront built with React and Vite. It provides a simple and enjoyable shopping experience with product browsing, category filtering, cart management, and a simulated checkout process.

## Features

- **Product Catalog:** Fetches product information from the Fake Store API.
- **Search:** Find products by searching the catalog.
- **Category Filtering:** Browse products by category.
- **Shopping Cart:** Add products, adjust quantities, and remove items.
- **Cart Persistence:** Saves cart contents in browser local storage.
- **Price Calculation:** Displays subtotal, tax, shipping, and order total.
- **Simulated Checkout:** Provides a checkout form and order confirmation without processing real payments.
- **Responsive Design:** Adapts the interface for desktop and mobile screens.
- **Modern Interface:** Uses a soft lavender, pink, and cream color palette.

## Built With

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Fake Store API

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before running the project.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/janetaborvor-cs/Datheon-Task4-ShopLuxe.git
   ```

2. Navigate into the project folder:

   ```bash
   cd Datheon-Task4-ShopLuxe
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.

## API

ShopLuxe uses the [Fake Store API](https://fakestoreapi.com/) to retrieve sample product data. An internet connection is required to load products from the API.

## Checkout Notice

The checkout process is for demonstration purposes only. It does not process real payments or place actual orders.
